# `enter_plan_mode`

请求用户把 miro 内置 agent 从 Default 切换到 Plan 模式。只在交互式 Default 模式中暴露；非交互运行、ACP provider、已经处于 Plan 模式时都不可用。

## 参数

无参数。

## 行为

用户确认后，运行时为本次会话独占创建规范计划文件，持久化 Plan 状态，并结束当前回合。UI 随后以原任务开启新的规划回合。用户拒绝时留在 Default 模式，工具结果要求模型继续正常处理，且不要重复请求。

它适用于用户明确要求实现计划，或实现确实存在会造成大量返工的架构分歧；普通多文件任务不应自动进入。

## 权限与限制

该工具本身不修改项目。活动目标处于 `pending`、`active` 或 `pausing` 时不能进入 Plan 模式。

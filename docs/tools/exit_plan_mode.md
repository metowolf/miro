# `exit_plan_mode`

提交规范计划文件供用户审阅。只在交互式 Plan 模式中暴露。

## 参数

无参数。计划正文不通过工具参数传递；运行时只从当前 Plan 状态记录的规范路径读取，拒绝空文件、无效 UTF-8 与超过 256 KiB 的文件。

## 审阅结果

- **批准并实现**：冻结刚读取的精确文本，退出 Plan 模式，结束当前回合；UI 把冻结计划写入 transcript，并用它开启一个全新的实现回合。后续即使文件改变也不会改变已批准快照。
- **要求修改**：把反馈回灌给模型，继续留在 Plan 模式。
- **拒绝**：退出 Plan 模式并结束回合，不实施计划。
- **关闭审阅框**：保留 Plan 模式并结束当前回合，稍后可以继续。

## 权限与限制

Plan 模式保留普通工具能力，不额外限制 Terminal、文件写入或子智能体。工具调用继续遵守当前 `Auto` / `Manual` 权限档位；“只规划、不实施”由系统提示约束。
